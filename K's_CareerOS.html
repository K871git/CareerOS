What is CareerOS

Built for engineers learning the craft

CareerOS is not a quiz app. It is a structured learning and practice system that guides users from fundamentals to advanced concepts — tracking progress, surfacing weak areas, and forcing mastery before progression.

🎓

Placement Students

Go from zero to interview-ready with structured tracks, concept lessons, and real MCQ practice.

💻

Junior Devs (0–2 yr)

Fill concept gaps, practice under exam conditions, and track what needs work — systematically.

⚡

Mid-level Engineers (2–5 yr)

Revisit fundamentals, tackle advanced topics, and prepare for senior-role interviews.

Features

Everything users need to prepare

Six core systems, each solving a specific part of the interview-preparation journey.

🔐

Auth & Profile

Secure registration and login with Sanctum tokens. Profile completeness tracking — users fill their stack, experience, and career goal before anything else.

🎯

Career Assessment

On first login users pick their target role, experience level, and strengths. This shapes their personalized learning track from day one.

📖

Learning System (5-Level Gate)

Each subject has 5 levels. Users must score 10/10 on a level exam to unlock the next. No skipping, no shortcuts — mastery first.

⚔️

Practice Arena

Four practice modes: MCQ, Theory, Scenario, and Mixed. Timed or untimed. Results go to the dashboard — wrong answers surface as weak areas.

🧑‍💻

Coding Playground

Real coding problems with a browser-based code editor. Submit your solution — evaluated against test cases. Covers DSA and real-world scenarios.

📊

Overview Dashboard

Single screen showing profile completeness, subjects attempted, level progress per track, XP, weak topics, and last active sessions — your KPI board.

User Journey

How it works

The full flow from signup to skill mastery.

Register & Set Up Profile

Create account → fill career goal, experience, and tech stack. Profile completeness % shown on dashboard.

Take Career Assessment

Answer 5–10 questions about your background. CareerOS recommends a starting track and level.

Study Lessons at Each Level

Read structured lesson content per topic. Each level has multiple lessons covering theory, patterns, and real-world usage.

Pass the Level Exam (10/10)

Take the 10-question MCQ exam. Score 10/10 to unlock the next level — anything less, study more and retry.

Practice & Track Progress

Jump to Practice Arena for MCQ, Theory, or Coding problems. Dashboard updates weak areas and overall progress automatically.

Test Coverage Checklist

What to verify before any release. Cover all areas — edge cases matter.

🔐 Auth

  • Register with valid email + password
  • Login returns token, persists session
  • Logout clears token, redirects to login
  • Duplicate email shows validation error
  • Invalid token returns 401 on protected routes

📖 Learning

  • Lessons load for all 5 levels
  • Level exam shows 10 questions
  • Score 10/10 → next level unlocks
  • Score less than 10 → level stays locked
  • Locked level shows overlay, not content

⚔️ Practice

  • All 4 modes load (MCQ, Theory, Scenario, Mixed)
  • Submit answer records result
  • Wrong answers appear in dashboard weak areas
  • Timer works and auto-submits on expiry

🧑‍💻 Playground

  • Problems load with description and test cases
  • Code editor accepts input
  • Submit evaluates against test cases
  • Empty submission shows validation error

📊 Dashboard

  • Profile completeness % updates on save
  • Level progress bars reflect actual data
  • Weak areas list populated after practice
  • Empty state shows when no data yet

🌐 Edge Cases

  • API errors show user-friendly message (toast)
  • Session expiry redirects to login
  • Network disconnect handled gracefully
  • Dark/light theme persists on refresh
