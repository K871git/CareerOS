# What is the imperative programming ?
-> imperative programming is simply telling the computer what to do in order and step by step
-> like traditional jquery->dom manipulation approach, telling the browser what to do with UI and manipulate the dom nodes

# What is react ? 
-- React is an javascript library for building user interfaces using reusable and composable components
-- React follows the declarative programming model, were I declare how the UI should look like based on the current state 
-- React handles the DOM updates efficiently 

# why react even exists?
-- manually manipulate DOM is ok for the small apps, but when application grows, then this become very dificult to manage it 
-- so react uses the UI components and compose those components and make an complex UI's possible and more organized

# what is virtual DOM?
Virtual DOM is an lightweight copy of the Real Browser DOM
when any change done by user or event clicks, the react make new VDOM and compare with Real DOM and update only part of the Real DOM without changing full page 

# When we return component: at least one parent must be return by the component 
not : return (
  <h1>Hello</h1>
  <p>Welcome</p>
);

correct : return (
  <div>
    <h1>Hello</h1>
    <p>Welcome</p>
  </div>
);

# what is fragment in react? 
when i want to return multiple element from component but dont want the extra div as parent then i use parent 
1) : it works but it adds extra div in the html
return (
  <div>
    <h1>Hello</h1>
    <p>Welcome</p>
  </div>
); 

2) : this does not create extra div element in html
return (
  <>
    <h1>Hello</h1>
    <p>Welcome</p>
  </>
);
