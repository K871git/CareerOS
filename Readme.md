# CareerOS — The Path for NextGen Engineers!

> A modern engineering growth platform for students and software engineers.

---

## What is CareerOS?

CareerOS is **not** an interview prep site or a quiz bank.

It is a platform for building real engineering judgment — helping developers
understand fundamentals deeply, practice real engineering problems, measure
their progress honestly, and evolve with the changing landscape of
AI-assisted software development.

### Five Core Pillars

| Pillar | What it does |
|--------|-------------|
| **Understand** | Teach concepts deeply — what, why, how, trade-offs, real examples |
| **Practice** | MCQs, scenario-based, debugging, code review problems |
| **Measure** | Track performance, identify weak areas, measure improvement |
| **Explain** | AI-powered hints and explanations (local Ollama LLM) |
| **Evolve** | AI-assisted development, modern engineering practices |

## Tech Stack

**Backend**
- Laravel 13 · PHP 8.3+ · MySQL
- Laravel Sanctum · Socialite (Google OAuth)

**Frontend**
- React · TypeScript · Vite
- TanStack Query (React Query)

**AI**
- Ollama · llama3.2:3b (local LLM — runs on dev machine)

**Deployment**
- Netlify (frontend) · Render (backend) · Railway (MySQL)

---

## Features

- Email / password auth with OTP verification
- Google OAuth (account linking)
- Learning tracks → subjects → topic levels → exams
- Theory MCQ system (8 engineering areas, 3 levels each)
- Practice/Assessment (topic MCQs with difficulty breakdown)
- AI Hint system (50-point cost, Ollama-powered, fast one-sentence hints)
- AI Explanation panel (post-quiz answer explanations)
- Gamification — points system with full audit log
- Code syntax highlighting in MCQ questions
- Code Playground (PHP, Python, JavaScript, MySQL)
- Coding Battleground
- Dashboard with progress analytics
- DPDP Act 2023 (India) compliant consent system
